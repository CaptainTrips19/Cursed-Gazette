Players

Add yourself first, then anyone you play with. Click a player to show them alone, and a second to compare the two as a duo. Works with a steamcommunity.com/profiles link, a 17-digit SteamID, or a Steam friend code (the number on Steam's Add a Friend page). You can also type a Steam name and pick from the matches. Players are remembered in this browser.

Matches on record

The Deadlock API doesn't hold every match. For most players it only has the matches it has been sent or has fetched itself, so some games never reach this page. A game together only counts here when it is on record for both of you.

To fill the gaps: the API's own background tool sends each match you play from then on, plus whatever is already in your Steam cache. Once a match is sent, it is recorded for everyone who played in it, so only one of you needs the tool for your shared games to show up. The API's patron tier (from $1.50 a month per account) gives full history from first game to last.

Also check the Mode menu: Street Brawl games are hidden unless Mode is set to Street Brawl or Everything.

Export for tuning

Saves a small file with each player's stat ranges, achievement progress, a plain list of match figures and a log of how the page's lookups went. It has no names, Steam IDs or real match IDs in it, so it is safe to hand over for tuning thresholds or chasing a bug.
